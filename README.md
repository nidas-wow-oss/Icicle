# Icicle Enhanced

Enemy cooldown icons above nameplates for World of Warcraft 3.3.5a (WotLK).

When an enemy player uses a tracked ability (PvP trinket, Blink, Kick, Deterrence…), an icon with a cooldown spiral appears above their nameplate, so you can see at a glance what they still have available.

## Features

- Icons above enemy nameplates with the remaining cooldown.
- Orange border on interrupts.
- **Readiness**, **Preparation** and **Cold Snap** clear the cooldowns they reset.
- Works in any client language (spells are matched by ID).
- **Wrap into rows**: icons keep their size and stack in rows instead of shrinking when an enemy has many cooldowns up.
- Enable it in arenas, battlegrounds, the open world, or everywhere.
- Adjustable icon size, icons per row and X/Y offsets.
- Profiles (Ace3).

## Installation

1. Download this repository (**Code → Download ZIP**).
2. Copy the `Icicle` folder into `World of Warcraft/Interface/AddOns/`.
3. Make sure **Icicle Enhanced** is enabled in the AddOns list on the character select screen.

## Usage

Type `/icicle` to open the options.

## Requirements

- WotLK 3.3.5a (Interface `30300`)
- Libraries are included (Ace3).
